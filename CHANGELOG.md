# Changelog

All notable changes to Carnot are documented in this file.

## [0.1.0] - 2026-11-26

### Added
- **Core Rust Agent Engine (`#![forbid(unsafe_code)]`)**: Effect-parallel async turn loop, live tool progress streaming (`ToolProgressSink` → `AgentEvent::ToolUpdate` with secret redaction across TUI, REPL, RPC, HTTP SSE, and ACP), lossless `EventLog`, crash-safe branching JSONL v2 session store with O(N) reload and delta-calibrated token estimation, and BLAKE3 content-addressed spill store with pre-spill secret redaction plus deterministic compressors (`cargo`, `pytest`, `jest`/`vitest`, `tsc`, `eslint`, `go test`, package/docker build chatter, oversized `git diff`/`show`, and O(1)-memory multi-line stack-cycle collapser).
- **Prefix-Invariant Prompt Caching**:
  - Ultra-slim cross-directory byte-identical static system prompt (`986` chars) + 5 canonical tool schemas verified by `carnot audit-prefix`.
  - Provider-agnostic `CacheTtl` retention tiers (`short`, `hybrid`, `long`, with `5m`/`1h`/`24h` aliases) configurable via CLI (`--cache-ttl`), `~/.carnot/config.toml`, TUI (`/cache`), RPC (`set_cache_ttl`), HTTP (`POST /v1/cache-ttl`), and ACP (`cache_ttl`).
  - `SessionMetrics::prefix_retention_rate()`, runtime `CacheBreakDetected` monitoring, and smart subagent cache retention policies.
  - Two-tier cache-warm semantic compaction.
- **5 Surgical Core Tools**: Multimodal `Read` with tree-sitter outlines, `ReadTracker` (absolute-line re-read diffs + shift notices, symbol/outline tracking), atomic fuzzy & harness-anchored line-range `Edit` (implicit line verification + unique relocation, CAS undo, silent Tier-0 syntax delta for Rust/Python/TS/Go plus `.json`/`.toml` with bounded offending-line snippets), `Write` with `.git` protection and unread/stale-file overwrite guard, workspace-confined `ignore`/`globset` `Grep`, and sandboxed `Bash` with adaptive yield, native `rustix` process-group cleanup, non-interactive shell env defaults, and interactive OS-sandboxed PTY mode (`pty: true` + `stdin`).
- **Sparse Calendar Date Grounding**: Persisted `[date: YYYY-MM-DD]` note injected once on Turn 1, preserved across compaction, and re-emitted only on calendar day change — keeping the static system prompt 100% byte-invariant.
- **Fail-Closed OS Sandboxing**: macOS Seatbelt and Linux `bwrap` (protecting credentials such as `~/.ssh`, `~/.aws`, `~/.carnot/auth.json`, `~/.carnot/server.token` and locking `.git` read-only), plus Linux Landlock (ABI v1–v6, fail-closed on ABI < v4 when offline network isolation is requested) self-exec fallback for containers where `bwrap` is unavailable (note: Landlock is additive allow-only and cannot carve `.git` out of a writable workspace; in-process `Edit`/`Write` always block `.git` writes).
- **21 Built-in Providers (+ offline `faux`) & Multi-Protocol `model_routes`**: Anthropic, OpenAI Completions & Stateless Responses, Google Gemini & Cloud Code, Grok / xAI (`grok-4.7` Responses + sticky `x-grok-conv-id`), Muse / Meta (`api.meta.ai/v1`), Mistral (`alnum9` tool IDs + structured thinking), OpenCode Zen & OpenCode Go multi-protocol gateways, OpenRouter, DeepSeek, Kimi, Qwen, Groq, Fireworks, Together, Cerebras, Ollama, LM Studio, vLLM, and offline `faux`, plus OAuth 2.0 (`carnot auth`).
- **Built-in & Drop-in Extensions**: `web`, `lsp`, `subagent`, `memory`, `codemode` (isolated QuickJS async sandbox with `Promise.all`, `tools.*`, fuzzy tool suggestions, WHATWG `URL`/`TextEncoder`/`TextDecoder`/`structuredClone`/`crypto.randomUUID`, stdlib helpers, smart `defer_loading`, transactional `store`/`load`, gated via `Agent::invoke_tool_gated`, and BLAKE3 CAS spill), `goal` (`carnot-ext-goal` — autonomous verification loop with live `GoalController` across TUI `/goal`, RPC, HTTP, Python & TS SDKs, revision-guarded `set`/`clear`, deterministic `--goal-cmd` checks, and independent virgin-context Worker ≠ Verifier LLM judge), `hooks`, `claude-plugins`, full MCP (`2026-07-28`, `2025-11-25`, legacy SSE), and `carnot-ext/1` drop-in file extensions.
- **Multi-Surface UX, SDKs & Benchmarks**: Dedicated optional `carnot-tui` crate (live mid-turn steer & follow-up, `/context`, `/cache`, `/goal`, `/fleet`, `/fork`, `/undo`, `^P` model picker), plain REPL, ACP stdio, Host RPC stdio, Bearer-authenticated HTTP/SSE server (`carnot serve`), zero-dependency Python & compiled ESM TypeScript SDKs, `~/.carnot/config.toml`, opt-in cost-capped live smoke suite (`scripts/live_smoke.py`), and 3-tier budget-friendly benchmarking (`benchmarks/README.md`, `benchmarks/harbor_carnot_agent.py`, `benchmarks/summarize_harbor_run.py`).
